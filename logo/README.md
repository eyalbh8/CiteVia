# Zyqon.io logo

The mark is a Q ring whose opening lets the Z's bottom stroke run out as the Q tail: one continuous "answer" stroke inside the ring. Drawn as two paths with round caps, so it scales from favicon to billboard.

| File | Use |
|---|---|
| `zyqon-mark.svg` | Mark, mint-to-periwinkle gradient, for dark backgrounds |
| `zyqon-mark-light-bg.svg` | Mark, teal-to-indigo gradient, for white or light backgrounds |
| `zyqon-mark-mono.svg` | Mark in `currentColor`, for single-colour contexts |
| `favicon.svg` | Mark on a rounded ink tile |
| `zyqon-logo-dark.svg` / `zyqon-logo-light.svg` | Horizontal lockup. Text is live SVG text in Inter and JetBrains Mono; install the fonts or use the PNGs where fonts cannot be guaranteed |
| `zyqon-logo-dark.png` / `zyqon-logo-light.png` | Horizontal lockup rendered at 1776x512 with the fonts baked in |
| `zyqon-mark.png` / `zyqon-mark-on-white.png` | Mark at 512x512 |

Clear space: half the ring's diameter on every side. Minimum mark size: 20px. Do not rotate, outline, or recolour outside the two gradients and mono.
